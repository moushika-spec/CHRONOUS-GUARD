Industrial Bearing Health Monitoring Dashboard

Course: 23AID205 - Artificial Intelligence & Data Science Project

i. Introduction & Motivation

Mechanical bearing failures account for over 40% of industrial machinery breakdowns. Unplanned downtime leads to millions of dollars in losses. This project builds a real-time predictive maintenance dashboard using machine learning to detect bearing degradation early and predict Remaining Useful Life (RUL).

ii. Problem Statement & Relevance

Traditional reactive and preventive maintenance strategies are either too late or unnecessarily costly. By analyzing high-frequency 20kHz vibration telemetry from NASA IMS bearings, our AI pipeline provides continuous condition monitoring, reduces unplanned downtime, and optimizes maintenance schedules.

iii. Objectives & Scope

  • Ingest and process 20kHz continuous vibration telemetry signals.
  • Detect operational anomalies using an unsupervised Isolation Forest model.
  • Forecast Remaining Useful Life (RUL) using a Random Forest Regressor.
  • Translate predictive health metrics into financial ROI ($29.6M+ estimated savings).
  • Automate work orders via industrial CMMS webhook API integration.

iv. Methodology

1. Dataset

NASA IMS Bearing Dataset containing 40,964 vibration signal snapshots tracked across run-to-failure cycles.

2. Feature Engineering

Extracted Windowed Kurtosis (impulsive shocks), Rolling Z-Score (baseline drift), and FFT Frequency Peak Anomalies.

3. Model Selection & Trade-Off Benchmarks

Architecture RUL RMSE (Cycles) Edge Latency (ms) Memory Footprint Deployment Decision
Linear Thresholding 18.4 < 1.0 ms < 1 MB Rejected (Linear Drift Assumption)
Random Forest Regressor 4.2 12.4 ms 12 MB Selected (Optimal Edge Accuracy/Speed)
XGBoost Regressor 4.0 18.2 ms 15 MB Evaluated (Higher Overhead)
LSTM Deep Neural Network 3.8 145.0 ms 85 MB Rejected (High Edge Memory Footprint)

v. Results & Discussion

The deployed Random Forest model achieved a low RUL RMSE of 4.2 cycles with an inference latency of 12.4ms. The integrated ROI engine calculated an estimated $29,607,500 in downtime cost savings across 911 critical bearing detections.

vi. Conclusion & Future Scope

The system successfully bridges high-accuracy ML predictions with actionable industrial workflows. Future scope includes flashing models onto physical ESP32 microcontrollers and subscribing directly to live MQTT shop-floor telemetry streams.
